___*Orçamento MZ - Plataforma de Gestão Orçamental Municipal*__

O Orçamento MZ é uma plataforma web para gestão orçamental municipal. Foi desenvolvida para melhorar a transparência, a eficiência administrativa e o controlo financeiro em municípios moçambicanos.

🚀 __Funcionalidades Principais__
*Centralização de Dados:* Registo centralizado de receitas e despesas.
*Organização por Categorias:* Orçamentos organizados por sectores como saúde, educação e infraestruturas.
*Dashboards Analíticos:* Indicadores financeiros em tempo real para monitorização da execução orçamental.
*Segurança Avançada:* Autenticação via JWT, criptografia de senhas com BCrypt e controlo de acesso por perfil (RBAC).
*Auditoria:* Logs de auditoria para garantir a integridade e rastreabilidade dos dados.
*Alertas de Limite:* Mecanismos automáticos para alerta de limite orçamental.

__🛠️ Tecnologias Utilizadas__
O sistema segue uma arquitetura Cliente-Servidor em camadas (Apresentação, Negócio e Persistência).
*Backend (Java)*
--Java 17+ com framework Spring Boot.
--Spring Data JPA e Hibernate ORM.
--Spring Security para proteção da API.
--Maven como ferramenta de build.

__Frontend (Em densenvolvimento)__
--React com Vite.
--TanStack Query e Axios para integração e gestão de dados.
--Tailwind CSS para estilização moderna.
--Recharts para visualização de dados.

__Infraestrutura e Base de DadosPostgreSQL:__
*Sistema de gestão de base de dados.*
--Docker: Contêinerização da aplicação.
--Render: Hospedagem em ambiente de produção.*(podemos utilizar varias outras tecnologias identicas para deploy)*
--Git/GitHub: Versionamento e repositório de código.

__📈 Impacto e Objetivos__
O projeto visa reduzir erros administrativos e promover a transparência pública em Moçambique, fornecendo uma base tecnológica escalável para futuras integrações com sistemas nacionais.
